# Juan-Motta/homebrew-tap

Homebrew casks for my projects.

```bash
brew install --cask juan-motta/tap/<cask>
```

| Cask | Description |
| --- | --- |
| [`dbforge`](https://github.com/Juan-Motta/dbforge) | Native database client for PostgreSQL, MySQL, MariaDB, SQLite, SQL Server, MongoDB, Cosmos DB and Redis |
| [`discord-apple-music`](https://github.com/Juan-Motta/discord-apple-music) | Show Apple Music playback as a Discord "Listening to" Rich Presence |
